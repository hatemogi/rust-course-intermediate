# 반박 가능성과 완전한 분기

항상 값과 매칭<sub>matching</sub>되는 패턴을 반박 불가능한
패턴<sub>irrefutable pattern</sub>이라고 합니다. `let x = value`와 튜플의 모든
원소를 받는 패턴이 여기에 속합니다. 실패를 처리할 필요가 없는 `let`과 함수
매개변수에는 이런 패턴만 쓸 수 있습니다.

입력에 따라 매칭되지 않을 수 있는 패턴은 반박 가능한
패턴<sub>refutable pattern</sub>입니다. 예를 들어 `Some(value)`는 입력이
`None`이면 매칭되지 않습니다. 일반 `let`에는 쓸 수 없고 `if let`,
`let else`, `match`처럼 매칭 실패를 처리할 수 있는 곳에서 사용합니다.

`match`는 위에서 아래로 차례로 갈래<sub>branch</sub>를 확인하며, 처음 매칭된 갈래의 식만
실행합니다. 또한 가능한 모든 값을 처리해야 하므로 아직 다루지 않은 경우가 있으면
컴파일러가 알려 줍니다.

## 나머지 경우를 한꺼번에 처리하기

실행 중인지에 따라 문구를 표시하려면 `Status::Running`을 먼저 확인하고, 나머지 경우는
`_`로 처리할 수 있습니다. 다음 코드에서 `Status::Ready`와 `Status::Done`은
모두 `_`에 매칭되어 `"실행 중 아님"`이 됩니다.

```rust

```

`_`는 나머지 모든 경우를 처리하지만 새로운 열거형<sub>enum</sub>
변형<sub>variant</sub>이 추가되어도 컴파일 오류가 나지 않습니다. 모든 변형을
명시하면 열거형이 바뀌었을 때 수정할 위치를 컴파일러가 알려 줍니다.

## 사용 위치 비교

| 사용 위치 | 사용할 수 있는 패턴 | 매칭되지 않을 때 |
|---|---|---|
| 일반 `let`·함수 매개변수·`for` | 반박 불가능 | 처리 경로가 없음 |
| `if let`·`while let` | 두 종류 모두 | 분기를 건너뛰거나 반복을 끝냄 |
| `let else` | 두 종류 모두 | `else` 블록에서 제어 흐름을 끝냄 |
| `match` | 두 종류 모두 사용 가능 | 모든 값을 갈래로 빠짐없이 처리함 |

실패를 처리할 수 없는 위치에는 반박 불가능한 패턴만 쓸 수 있습니다.
`if let`, `while let`, `let else`에도 반박 불가능한 패턴을 쓸 수는 있지만,
매칭 실패가 일어나지 않으므로 보통 컴파일러가 '불필요한 사용'이라고 경고합니다.
