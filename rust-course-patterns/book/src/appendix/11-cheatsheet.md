# 패턴 문법 한눈에 보기

목적에 맞는 패턴을 고른 뒤 바인딩 타입과 분기 순서를 확인하세요.

## 값과 조건 확인하기

| 목적 | 예 |
|---|---|
| 모든 값 받기 | `name`, `_` |
| 사용하지 않는 값 바인딩 | `_name` |
| 정확한 값 | `0`, `"quit"` |
| 끝값 제외 범위 | `1..10` |
| 끝값 포함 범위 | `1..=9` |
| 한쪽 경계를 생략한 범위 | `..0`, `100..` |

## 구조를 분해하고 조건 조합하기

| 목적 | 예 |
|---|---|
| 여러 패턴 | `"y" \| "yes"` |
| 튜플 분해 | `(x, y)` |
| 구조체 분해 | `Point { x, y: 0 }` |
| 열거형 분해 | `Some(value)` |
| 나머지 생략 | `Point { x, .. }`, `[first, ..]` |
| 나머지 구간 바인딩 | `[first, rest @ ..]` |

## 추가 검사와 바인딩

| 목적 | 예 |
|---|---|
| 추가 조건 | `value if value > limit` |
| 검사하며 바인딩 | `id @ 1..=9` |
| 패턴과 매칭<sub>matching</sub>되는지 확인 | `matches!(value, pattern)` |
| 내부 값을 빌리기 | `Some(ref value)` |
| 내부 값을 변경할 수 있게 빌리기 | `Some(ref mut value)` |
| 참조 분해하기 | `let &value = &7;` |

## 소유권 확인하기

`_`는 값에 이름을 붙이지 않지만 `_name`은 이름을 붙입니다. 소유권 이동을 피하려고
값을 완전히 무시할 때는 `_`를 사용하세요. 값 바인딩은 `Copy` 타입이면 복사하고,
그렇지 않으면 이동합니다. 원본이 계속 필요하면 대상을 참조로 받거나 `ref`로
내부 값을 빌립니다.
