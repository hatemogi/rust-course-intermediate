# 우아한 Rust 중급: 문자열 활용

Rust에서 문자열을 소유하고 빌리며 UTF-8 텍스트를 안전하게 처리하는 방법을
배웁니다. `String`과 `&str`을 구분하고, 문자와 바이트 가운데 무엇을 세어야 하는지
판단하며, 호출하기 편한 문자열 API를 설계합니다.

## 이 강의의 핵심

- `String`, `str`, `&str`의 관계를 소유권과 메모리 관점에서 이해합니다.
- UTF-8 문자열을 바이트, 유니코드 스칼라 값, 사용자에게 보이는 글자 관점에서
  구분합니다.
- 문자열을 만들고 수정하고 검색하고 나누는 표준 API를 익힙니다.
- 입력은 빌리고 결과는 필요한 만큼만 소유하도록 함수 경계를 설계합니다.
