# 문자열과 숫자 변환하기

숫자를 문자열에 넣어 표시하거나, 입력받은 문자열을 계산에 사용하려면 두 타입
사이를 변환해야 합니다. 변환하는 방향에 따라 사용하는 메서드와 실패 가능성이
다릅니다.

## 숫자를 문자열로 바꾸기

숫자의 일반적인 표기를 그대로 `String`으로 만들 때는 `to_string`을 사용합니다.
자릿수·정밀도·부호 같은 표시 형식을 지정해야 한다면 `format!`을 사용합니다.

```rust
{{#include ../../../examples/07_convert.rs:number_to_string}}
```

두 방법 모두 새로운 `String`을 만듭니다. `to_string`은 기본 표시 형식을 사용하고,
`format!`은 앞 장에서 배운 서식 지정 문법을 적용할 수 있습니다.

## 문자열을 숫자로 바꾸기

문자열을 숫자로 바꿀 때는 `parse`를 사용합니다. 만들 숫자 타입을 변수의 타입이나
터보피시 문법으로 알려 주어야 합니다.

```rust
{{#include ../../../examples/07_convert.rs:string_to_number}}
```

`parse`는 변환에 성공한 값이나 실패 원인을 담은 `Result`를 반환합니다. 정수와
부동소수점 타입에 따라 허용하는 문자열 형식도 다릅니다.

## 변환 실패 처리하기

숫자 이외의 문자가 섞였거나 대상 타입의 범위를 벗어나면 변환에 실패합니다.

```rust
{{#include ../../../examples/07_convert.rs:parse_error}}
```

실패를 기본값으로 조용히 바꾸면 잘못된 입력을 알아차리기 어렵습니다. 함수 안에서
복구 기준이 분명하지 않다면 `Result`를 호출자에게 돌려주는 편이 낫습니다.
