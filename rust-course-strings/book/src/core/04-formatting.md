# `format!`으로 서식 지정하기

`format!`은 값을 지정한 형식에 맞춰 새로운 `String`으로 만듭니다. 화면에는
아무것도 출력하지 않으며, 만들어진 문자열의 소유권을 호출자에게 돌려줍니다.
`println!`과 `write!`도 같은 서식 문자열 문법을 사용합니다.

## 값을 서식 문자열에 넣기

`{}`는 인자를 순서대로 표시합니다. 변수 이름을 중괄호 안에 직접 쓰거나,
이름을 붙인 인자를 여러 자리에서 사용할 수도 있습니다.

```rust
{{#include ../../../examples/04_formatting.rs:values}}
```

대부분의 값은 사용자에게 보여 줄 문자열을 만드는 `Display` 구현으로 표시합니다.

## 폭·정렬·채움 문자 지정하기

콜론 뒤의 숫자는 결과가 차지할 최소 폭을 지정합니다. `<`는 왼쪽, `>`는 오른쪽,
`^`는 가운데로 정렬합니다. 정렬 기호 앞에 채움 문자도 지정할 수 있습니다.

```rust
{{#include ../../../examples/04_formatting.rs:alignment}}
```

폭은 결과가 짧을 때만 채움 문자를 추가합니다. 결과가 지정한 폭보다 길더라도
잘라내지 않습니다. 폭을 변수로 정하려면 `{word:>width$}`처럼 `$`를 붙입니다.

## 정수를 여러 형식으로 표시하기

정수는 `b`로 2진수, `o`로 8진수, `x`와 `X`로 16진수를 표시할 수 있습니다.
`#`을 붙이면 진법을 나타내는 접두사가 추가됩니다.

```rust
{{#include ../../../examples/04_formatting.rs:integers}}
```

`+`는 양수에도 부호를 표시합니다. `05`는 최소 폭을 5로 맞추고 빈자리를 `0`으로
채웁니다. C의 `%05d`와 비슷한 결과가 필요할 때 이 표기를 사용합니다.

## 부동소수점 자릿수 지정하기

점 뒤의 숫자는 소수점 아래에 표시할 자릿수를 정합니다. 표시하지 않는 자릿수는
반올림합니다.

```rust
{{#include ../../../examples/04_formatting.rs:floats}}
```

`8.2`에서 `8`은 전체 최소 폭, `2`는 소수점 아래 자릿수입니다. 정밀도를 변수로
정할 때는 `{value:.precision$}`처럼 작성합니다.

## 디버그 형식으로 표시하기

`Display`가 구현되지 않은 값이나 내부 구조를 확인할 때는 `{:?}`를 사용합니다.
`{:#?}`는 같은 값을 여러 줄로 펼쳐 읽기 쉽게 만듭니다.

```rust
{{#include ../../../examples/04_formatting.rs:debug}}
```

디버그 형식은 개발 중 값을 확인하기 위한 표현입니다. 사용자에게 보여 줄 문구처럼
출력 형식을 일정하게 관리해야 한다면 `Display`를 구현하거나 필요한 값을 직접
서식 문자열에 넣는 편이 좋습니다.
