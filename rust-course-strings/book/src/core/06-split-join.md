# 문자열을 쪼개고 합치기

문자열을 쪼개는 메서드는 대부분 원본을 빌린 `&str`을 차례로 돌려줍니다. 쪼갠
부분을 읽기만 한다면 새로운 `String`을 만들 필요가 없습니다.

## 공백을 기준으로 쪼개기

`split_whitespace`는 연속된 공백을 하나의 경계처럼 다루고, 문자열 앞뒤의 공백도
건너뜁니다.

```rust
{{#include ../../../examples/06_split_join.rs:split_whitespace}}
```

반면 `split(' ')`은 공백 하나하나를 구분자로 삼으므로 연속된 공백 사이에서 빈
문자열도 만듭니다.

## 구분자를 기준으로 쪼개기

`split`은 지정한 구분자가 나올 때마다 문자열을 쪼갭니다.

```rust
{{#include ../../../examples/06_split_join.rs:split}}
```

구분자가 연달아 나오면 그 사이에 빈 문자열도 만듭니다. 빈 항목을 제외해야 한다면
예제의 `colors`처럼 `filter`를 이어서 사용합니다. `is_empty`로 각 조각이 빈
문자열인지 확인하고, 비어 있지 않은 조각만 남깁니다.

## 한 번만 쪼개기

`split_once`는 처음 만난 구분자를 기준으로 문자열을 두 부분으로 쪼갭니다.
구분자가 없으면 `None`을 반환하므로 그 경우를 호출자가 처리해야 합니다.

```rust
{{#include ../../../examples/06_split_join.rs:split_once}}
```

설정이나 헤더처럼 왼쪽과 오른쪽을 한 번만 구분하면 되는 값을 읽을 때 편리합니다.

## 문자열 목록을 구분자로 합치기

문자열 배열은 슬라이스로 변환되어 `join`을 사용할 수 있습니다. `join`은 각
문자열 사이에만 구분자를 넣고, 새로운 `String`을 돌려줍니다.

```rust
{{#include ../../../examples/06_split_join.rs:join}}
```

원래 목록은 소비하지 않으므로 `join`을 호출한 뒤에도 계속 사용할 수 있습니다.

## 숫자 목록을 문자열로 합치기

숫자 배열에는 문자열 구분자를 사용해 곧바로 `join`을 호출할 수 없습니다. 먼저
각 숫자를 `String`으로 바꾼 뒤 그 결과를 모아야 합니다.

```rust
{{#include ../../../examples/06_split_join.rs:number_join}}
```

Rust는 숫자를 문자열로 암묵적으로 바꾸지 않습니다. 어떤 형식으로 표시할지
`to_string`이나 `format!`으로 명시해야 합니다.
