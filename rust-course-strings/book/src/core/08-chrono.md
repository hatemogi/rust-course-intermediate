# 날짜와 문자열 변환하기

Rust 표준 라이브러리는 날짜를 연·월·일로 표현하거나 날짜 문자열을 해석하는
기능을 제공하지 않습니다. 이런 작업에는 외부 크레이트인 `chrono`를 사용할 수
있습니다.

다음 명령을 프로젝트 디렉터리에서 실행해 의존성을 추가합니다.

```bash
cargo add chrono --no-default-features --features std
```

명령을 실행하면 `Cargo.toml`의 의존성 설정에 다음 내용이 추가됩니다.

```toml
chrono = { version = "0.4", default-features = false, features = ["std"] }
```

## 문자열을 날짜로 바꾸기

시간과 시간대가 없는 날짜는 `NaiveDate`로 표현합니다. `parse_from_str`에는
날짜 문자열과 그 문자열을 해석할 형식을 함께 전달합니다.

```rust
{{#include ../../../examples/08_chrono.rs:string_to_date}}
```

`%Y`는 네 자리 연도, `%m`은 두 자리 월, `%d`는 두 자리 일을 뜻합니다. 문자열이
지정한 형식과 다르거나 실제로 존재하지 않는 날짜라면 `Err`를 반환합니다.

## 날짜를 문자열로 바꾸기

날짜를 문자열로 표시할 때는 `format`에 원하는 형식을 전달한 뒤 `to_string`을
호출합니다.

```rust
{{#include ../../../examples/08_chrono.rs:date_to_string}}
```

같은 날짜 값도 형식 문자열에 따라 화면에 표시되는 모양을 다르게 만들 수 있습니다.

## 자주 쓰는 날짜·시간 형식 지정자

`chrono`의 형식 문자열에서는 `%`로 시작하는 지정자가 날짜와 시간의 각 부분을
나타냅니다.

| 지정자 | 의미 | 출력 예 |
|---|---|---|
| `%Y` | 네 자리 연도 | `2026` |
| `%m` | 두 자리 월 | `09` |
| `%d` | 두 자리 일 | `03` |
| `%H` | 24시간제 시 | `14` |
| `%M` | 분 | `30` |
| `%S` | 초 | `05` |
| `%a` | 축약한 요일 이름 | `Thu` |
| `%b` | 축약한 월 이름 | `Sep` |
| `%z` | 콜론 없는 UTC 오프셋 | `+0900` |
| `%:z` | 콜론이 있는 UTC 오프셋 | `+09:00` |

지정자를 일반 문자와 조합하면 `%Y-%m-%d`, `%Y년 %m월 %d일`,
`%Y-%m-%d %H:%M:%S`처럼 필요한 형식을 만들 수 있습니다.

## 오프셋이 포함된 날짜와 시간 변환하기

날짜·시간·UTC 오프셋이 함께 들어 있는 RFC 3339 문자열은
`DateTime::parse_from_rfc3339`로 읽을 수 있습니다.

```rust
{{#include ../../../examples/08_chrono.rs:date_time}}
```

이 예제의 `+09:00`은 UTC보다 9시간 빠른 고정 오프셋을 뜻합니다. `to_rfc3339`를
사용하면 날짜와 시간 값을 다시 표준 형식의 문자열로 만들 수 있습니다.

`NaiveDate`에는 시간대 정보가 없고, `DateTime<FixedOffset>`에는 문자열에서 읽은
UTC 오프셋이 들어 있습니다. 어떤 정보를 보존해야 하는지에 따라 타입을 선택해야
합니다.

`chrono`가 제공하는 타입·메서드·형식 지정자를 비롯한 자세한 내용은
[`chrono` 전체 API 문서](https://docs.rs/chrono/latest/chrono/)를 참고하세요.
