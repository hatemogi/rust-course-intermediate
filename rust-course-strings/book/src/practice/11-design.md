# 문자열 처리 기준 세우기

문자열 코드를 작성하기 전에 다음 질문부터 정합니다.

1. 입력을 읽기만 합니까, 저장합니까, 제자리에서 수정합니까?
2. 길이나 위치가 바이트 기준입니까, 유니코드 스칼라 값 기준입니까?
3. 결과가 원본의 일부라면 `&str`로 돌려줄 수 있습니까?
4. 대소문자와 공백을 바꾸는 규칙이 ASCII에만 적용됩니까?
5. 잘못된 입력을 건너뛸지 오류로 돌려줄지 요구 사항에 적혀 있습니까?

국제화된 텍스트의 화면 글자와 언어별 대소문자 규칙까지 정확히 다루려면 표준
라이브러리 밖의 전문 크레이트<sub>crate</sub>가 필요할 수 있습니다. 표준 API가 보장하는 범위를
알고 요구 사항을 그 범위와 맞추는 것이 중요합니다.
