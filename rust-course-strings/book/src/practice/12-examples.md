# 종합 예제

앞에서 배운 문자열 생성·검색·분리·결합·UTF-8 처리를 작은 함수로 조합해 봅니다.
각 함수는 입력을 `&str`이나 슬라이스로 빌리고, 새로운 문자열이 필요할 때만
`String`을 반환합니다.

## 연속된 공백 정리하기

```rust
{{#include ../../../src/lib.rs:normalize_spaces}}
```

`split_whitespace`로 앞뒤 공백과 연속된 공백을 건너뛰며 단어를 나눈 뒤, `join`으로
단어 사이에 공백 하나를 넣습니다. 결과를 새로 조립하므로 `String`을 반환합니다.

## 각 단어의 첫 문자 모으기

```rust
{{#include ../../../src/lib.rs:initials}}
```

공백 단위로 나눈 각 단어에서 첫 유니코드 스칼라 값을 꺼내고, `collect`로
`String`을 만듭니다. `filter_map`은 `chars().next()`가 반환한 `Option<char>`에서
문자가 있는 경우만 결과에 넣습니다.

## UTF-8 경계를 지키며 앞부분 가져오기

```rust
{{#include ../../../src/lib.rs:safe_prefix}}
```

바이트 인덱스로 문자열을 자르지 않고 `chars`로 순회합니다. 요청한 개수가 문자열의
유니코드 스칼라 값 개수보다 크더라도 `take`는 존재하는 값까지만 가져오므로
패닉하지 않습니다.

## 설정 문자열 나누기

```rust
{{#include ../../../src/lib.rs:split_setting}}
```

`split_once`로 첫 번째 `=`만 기준으로 삼아 키와 값을 나눕니다. 구분자가 없으면
`?`가 `None`을 곧바로 반환하고, 구분자가 있으면 양쪽의 불필요한 공백을 제거한
`&str` 두 개를 반환합니다. 반환값은 모두 원본 문자열을 빌립니다.

## 비어 있지 않은 문자열만 연결하기

```rust
{{#include ../../../src/lib.rs:join_nonempty}}
```

문자열 슬라이스를 순회하면서 빈 문자열을 `filter`로 제외하고, 남은 값만 지정한
구분자로 연결합니다. `join`이 새로운 `String`을 만듭니다.

## ASCII 문자열을 대소문자 구분 없이 가리기

```rust
{{#include ../../../src/lib.rs:redact}}
```

검색용 소문자 문자열을 따로 만든 뒤, 원본에서 일치한 위치 앞부분을 결과에 옮기고
찾은 단어 길이만큼 `*`를 넣습니다. 마지막으로 더 이상 일치하지 않는 나머지
문자열을 붙입니다. ASCII에서 대소문자를 바꿔도 바이트 길이가 같다는 성질을
이용하므로 함수 이름과 설명에서 ASCII 대상임을 분명히 합니다.
