# 우아한 Rust 중급: 개발 도구

Rust 코드를 작성하는 일과 그 코드를 믿을 만한 상태로 만드는 일은 다릅니다. 이
강의에서는 도구 체인을 맞추는 단계부터 컴파일, 형식 검사, lint와 테스트까지
이어지는 개발 흐름을 익힙니다.

## 이 강의의 핵심

- `rustup`, `rustc`와 Cargo가 각각 무엇을 관리하는지 구분합니다.
- 프로젝트 도구 체인과 패키지가 지원하는 가장 오래된 Rust 버전을 구분합니다.
- VS Code와 Zed에서 저장할 때 rustfmt와 클리피<sub>Clippy</sub>를 실행하도록
  설정합니다.
- 컴파일러와 클리피의 제안을 읽고 적용 여부를 판단합니다.
- 자동 수정 결과를 검토하고 의존성, 잠금 파일과 feature 구성을 관리합니다.
- `cargo tree`로 의존성 관계를 찾고 `cargo doc`으로 API 문서를 확인합니다.
- 단위·통합·문서 테스트가 각각 어떤 문제를 확인하는지 이해합니다.

종합 실습에서는 이름을 정돈하고 값을 검색하는 코드에 여러 검증 도구를 차례로
적용합니다. 도구의 출력을 그대로 따르지 않고 코드의 목적과 테스트 결과를 근거로
수정할지 판단합니다.
