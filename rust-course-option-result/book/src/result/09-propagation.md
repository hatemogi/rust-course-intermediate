# `?`로 오류 전파

`Result`에 `?`를 붙이면 `Ok`에서 값을 꺼낼 수 있습니다. `Err`라면 뒤의 코드를
실행하지 않고 현재 함수에서 그 오류를 바로 반환합니다. 이 장의 예제에서는
호출한 함수와 현재 함수가 같은 오류 타입을 사용합니다.

`?`는 오류를 무시하거나 숨기지 않습니다. 오류를 호출한 쪽으로 돌려보내면,
그쪽에서 다시 시도할지 사용자에게 알릴지 결정할 수 있습니다.

오류 타입이 다르면 먼저 `map_err`로 맞출 수 있습니다. 구체적인 방법은 다음
장의 [오류 종류를 열거형으로 구분하기](./10-error-types.md)에서 살펴봅니다.

입력은 `i32`로 읽고 합계는 `i64`로 계산합니다. 덧셈 전에 `as i64`로 타입을
바꾸면 두 수를 더해도 범위를 벗어나지 않습니다. 이 예제에서는 문자열을 숫자로
바꾸다가 생긴 오류를 호출한 쪽으로 돌려보내는 과정에 집중합니다.
