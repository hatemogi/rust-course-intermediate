# 우아한 Rust 중급: Option과 Result

값이 없거나 작업이 실패하는 상황을 타입으로 정확하게 표현하는 방법을 다룹니다.
API 사용법을 익히고, 함수를 호출하는 쪽에서 어떤 상태를 구분해야 하는지 살펴봅니다.
오류를 어디까지 전달하고 어디에서 처리할지도 함께 배웁니다.

## 이 강의의 핵심

- `None`과 `Err`가 나타내는 상황을 구분합니다.
- `map`, `and_then`, `collect`, `transpose`, `?`로 여러 처리 단계를 연결합니다.
- 열거형으로 오류의 종류를 구분하고, `map_err`로 오류 타입을 바꿉니다.
- 라이브러리에서 할 일과 이를 호출하는 프로그램에서 할 일을 구분합니다.
