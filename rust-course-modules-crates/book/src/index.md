# 우아한 Rust 중급: 패키지·크레이트·모듈

프로그램이 커지면 이름공간<sub>namespace</sub>을 나누어 이름 충돌을 막는 것만으로는
부족합니다. 어떤 코드가 어떤 책임을 맡는지, 외부에서 무엇을 사용할 수 있는지
명확히 구분하고, 변경 가능성이 큰 구현을 어디에 감출지 정해 구현이 바뀌더라도
외부에 미치는 영향을 줄여야 합니다.

Rust의 모듈<sub>module</sub>은 한 크레이트<sub>crate</sub> 안에서 이름공간을 만들고
항목의 공개 범위를 정합니다. 크레이트는 컴파일러가 처리하는 단위이며,
패키지<sub>package</sub>는 `Cargo.toml` 하나로 프로젝트의 빌드 방법과 의존성을
관리하는 단위입니다. 이 강의에서는 패키지에서 시작해 크레이트와 모듈로 이어지는
프로젝트 구조를 살펴봅니다. 각 단위를 정확히 구분하면 파일만 늘리는 데 그치지
않고 변경 범위를 관리하기 쉬운 경계를 만들 수 있습니다.

“우아한 프로그래밍 언어 Rust 입문” 강의를 들었다고 가정합니다.
