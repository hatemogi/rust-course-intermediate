# 우아한 Rust 중급: 패키지·크레이트·모듈

Rust 프로젝트의 패키지<sub>package</sub>, 크레이트<sub>crate</sub>,
모듈<sub>module</sub>을 구분하고 필요한 API만 공개하는 방법을 배웁니다. 한 파일의
코드를 쪼개는 문법에서 그치지 않고 라이브러리와 실행 파일의 경계를 정하고 외부
사용자가 읽기 좋은 공개 API를 구성합니다.

## 이 강의의 핵심

- 패키지·크레이트·모듈의 관계를 구분합니다.
- 모듈을 파일로 나누고 절대 경로와 상대 경로를 사용합니다.
- `pub`과 기본 비공개 규칙으로 지켜야 할 상태를 감춥니다.
- 재공개로 내부 배치와 외부 API 경로를 분리합니다.
